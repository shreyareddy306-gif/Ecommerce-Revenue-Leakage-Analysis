# Data Dictionary

## E-Commerce Revenue Leakage & Profitability Analysis

This document describes the 31 fields used in the synthetic e-commerce transaction dataset.

> **Note:** This project uses a synthetic e-commerce dataset created for data analytics and portfolio purposes.

| Column | PostgreSQL Type | Description |
|---|---|---|
| `order_id` | VARCHAR(50) | Unique identifier for each order |
| `order_date` | DATE | Date on which the order was placed |
| `customer_id` | VARCHAR(50) | Unique identifier for the customer |
| `customer_segment` | VARCHAR(50) | Customer segment associated with the order |
| `product_id` | VARCHAR(50) | Unique identifier for the product |
| `product_name` | VARCHAR(255) | Name of the product |
| `category` | VARCHAR(100) | Main product category |
| `sub_category` | VARCHAR(100) | Product sub-category |
| `region` | VARCHAR(50) | Geographic sales region |
| `state` | VARCHAR(100) | State associated with the transaction |
| `quantity` | INTEGER | Number of product units ordered |
| `unit_price` | NUMERIC(12,2) | Selling price per unit before discount |
| `gross_revenue` | NUMERIC(14,2) | Revenue before applying discounts |
| `discount_pct` | NUMERIC(6,2) | Discount percentage applied to the order |
| `discount_amount` | NUMERIC(14,2) | Monetary value of the discount |
| `sales` | NUMERIC(14,2) | Sales value after discount |
| `unit_cost` | NUMERIC(12,2) | Cost per unit of the product |
| `cogs` | NUMERIC(14,2) | Total cost of goods sold for the order |
| `shipping_cost` | NUMERIC(12,2) | Shipping cost associated with the order |
| `delivery_days` | INTEGER | Number of days taken to deliver the order |
| `payment_method` | VARCHAR(50) | Payment method used for the transaction |
| `order_status` | VARCHAR(50) | Current/final status of the order |
| `returned` | INTEGER | Indicator showing whether the order was returned |
| `return_reason` | VARCHAR(100) | Reason for return when applicable |
| `cancellation_loss` | NUMERIC(14,2) | Financial loss associated with order cancellation |
| `return_loss` | NUMERIC(14,2) | Financial loss associated with returned orders |
| `net_revenue` | NUMERIC(14,2) | Revenue retained after applicable order-level adjustments |
| `net_profit` | NUMERIC(14,2) | Final profit generated by the order |
| `profit_margin_pct` | NUMERIC(10,2) | Net profit expressed as a percentage of net revenue |
| `revenue_leakage` | NUMERIC(14,2) | Estimated revenue lost or leaked at order level |
| `leakage_reason` | VARCHAR(100) | Primary classification assigned to explain the revenue leakage |

---

## Financial Metrics

The dataset contains several financial stages that support revenue and profitability analysis:

```text
Gross Revenue
      ↓
Discount
      ↓
Sales
      ↓
Costs / Shipping / Order Outcomes
      ↓
Net Revenue
      ↓
Net Profit
```

These fields make it possible to analyze the difference between generating sales and generating profitable revenue.

---

## Revenue Leakage Fields

The main fields used for leakage analysis are:

- `discount_amount`
- `shipping_cost`
- `return_loss`
- `cancellation_loss`
- `revenue_leakage`
- `leakage_reason`

The `leakage_reason` field is used to classify orders into leakage-related analytical groups.

Examples present in the project analysis include:

- Low-Margin Product
- Return Loss
- High Shipping Cost
- Excessive Discount
- Cancellation Loss
- Healthy Order

---

## Profitability Fields

The primary profitability fields are:

```text
gross_revenue
sales
cogs
shipping_cost
net_revenue
net_profit
profit_margin_pct
```

These variables are used to compare revenue generation with actual profitability at product, category, customer-segment and regional levels.

## Dataset Scope

```text
Records:     100,000 orders
Columns:     31
Period:      January 2024 – December 2025
Data Type:   Synthetic E-Commerce Transaction Data
```

The dataset is intended for educational, analytical and portfolio demonstration purposes and should not be represented as real company transaction data.
